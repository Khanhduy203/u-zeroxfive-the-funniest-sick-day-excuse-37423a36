A one-line sick-day excuse, half believable and funny enough to quote: a good deed, a bad back, and a formal complaint with HR.

## Run

```sh
node main.ts
```

This writes the entry to `./output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Node 22+ required, standard library only — no dependencies.

## Entry

> Sorry, can't make it in today — I tried to jump-start my neighbour's car this morning, and my back has now filed a formal complaint with HR.
